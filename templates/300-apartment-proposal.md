## Project Scope & Specifications

### **Scope of Work**
- **300 apartment units** - Complete drywall installation and finishing
- **Common areas** - Hallways, lobbies, amenity spaces
- **Service areas** - Utility rooms, storage areas as specified
- **Fire-rated assemblies** where required by code

### **Materials & Standards**
- **Drywall:** 1/2" regular and 5/8" Type X fire-rated as per plans
- **Finishing:** Level 4 finish standard, Level 5 where specified
- **Compounds:** Premium lightweight compounds for superior finish
- **Fasteners:** Appropriate screws and nails per building code
- **Tape:** Paper tape for joints, mesh tape for repairs

### **Work Includes**
✓ Material delivery and staging  
✓ Drywall installation on walls and ceilings  
✓ Taping and mudding all joints and fasteners  
✓ Sanding to smooth, paint-ready finish  
✓ Corner bead installation (metal and paper)  
✓ Texture application where specified  
✓ Clean-up and debris removal  
✓ Final quality inspection
